# Public test artifacts

Version `0.1.0-research` is intentionally a research/testing release, not a production scanner driver.

Recommended public assets:

- `iriscan-express4-diagnostic_0.1.0_all.deb` — safe diagnostic package; does not install a scanner driver.
- `iriscan-express4-diagnostic-tools-0.1.0.tar.gz` — portable diagnostic scripts.
- `iriscan-express4-linux-0.1.0-research.tar.gz` — full source/research tree.
- `iriscan-express4-linux-0.1.0-research.zip` — same source/research tree as ZIP.
- `IRIScan-Express4-Release-SHA256SUMS.txt` — checksums.

Do not label this release as a working Linux driver until complete image acquisition is confirmed.
