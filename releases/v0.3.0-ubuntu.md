# IRIScan Express 4 for Ubuntu v0.3.0

## What to download

Download **`iriscan-express4-ubuntu-installer_0.3.0_all.deb`**. This is the only package an ordinary Ubuntu user needs from this release.

Automated WinBoat setup supports amd64 Ubuntu 24.04 or newer and validates the documented RAM/storage requirements.

Install it, as documented in `IRIScan-Express4-Ubuntu-QUICKSTART.txt`, then run:

```bash
iriscan-setup --install-winboat
```

## What it provides

- guided Ubuntu/architecture/scanner/WinBoat detection;
- optional download of the latest official amd64 WinBoat Debian package;
- mandatory verification against the SHA256 digest published by GitHub;
- a previewed, confirmed, narrowly scoped IRIScan USB passthrough edit;
- `iriscan-doctor`, `iriscan-uninstall`, and `iriscan-support-bundle`;
- Ubuntu application-menu launchers for Setup and Doctor;
- timestamped compose backups and idempotent setup/removal.

Installing this package alone does not edit or restart WinBoat.

## Required external software

WinBoat is MIT-licensed and downloaded from its official `winboat-org/winboat` GitHub project. It is currently beta and requires its documented virtualization, Docker/Compose, FreeRDP, RAM, storage, and amd64 prerequisites.

The IRIS/Avision Windows scanner package is proprietary and is not redistributed. Obtain it from licensed media or the official IRIScan Express 4 support section, then install it inside Windows.

## Native status

Native Linux remains experimental. Complete C3 image acquisition is not proven, `io.resid=78` remains unresolved, and this release does not install or claim a SANE backend.
