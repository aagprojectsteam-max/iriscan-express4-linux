# IRIScan Express 4 v0.2.0 — WinBoat support

## Working method

Ubuntu → WinBoat → Windows → official IRIS/Avision driver → IRIScan Express 4.

This release adds conservative tooling to detect WinBoat, preview and install the precise QEMU USB passthrough argument, verify host/container state, remove only that argument, and create a redacted support bundle. Existing QEMU arguments are preserved and every applied edit gets a timestamped backup.

Installing the Debian package is non-destructive. It does not edit compose, restart WinBoat, alter USB/storage mappings, or install proprietary Windows software.

## Native method

Native Linux remains experimental. Initialization, 300 DPI Color setup, paper movement, polling, and image-buffer discovery are proven. Complete C3 image transfer is not. The repeatable `io.resid=78` result remains under investigation; this release adds sentinel and SG status instrumentation rather than guessing around it.
